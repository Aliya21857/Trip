# Reisen — English Learning Game

## Overview

Open `english-game/index.html` in a modern browser and choose one of the four travel stations. No installation or account is required.

## Games

1. **Country Race** — look at each flag and choose its English country name.
2. **Dialogues** — read what a traveller says and choose the natural English reply.
3. **Sentence Train** — select word carriages in the correct order, use **Undo** if needed, then choose **Check train**.
4. **Where From?** — look at the flag and choose the matching “I’m from…” sentence.

## Scoring and controls

- Correct answers award 100 points plus a streak bonus.
- A wrong answer resets the streak but does not end the game.
- There is no timer or lives system.
- Use a mouse, touchscreen, or keyboard Tab/Enter controls.
- Press Escape to close an open game or instructions window.
- Best scores are saved locally in the browser.

## Project files

- Game: `english-game/index.html`
- Instructions: `GAME_INSTRUCTIONS.md`
- Visual assets: `english-game/assets/`

For local testing, start any static file server in the project directory and open `/english-game/`.
