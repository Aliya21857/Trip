# Reisen — English Learning Game

An A1 English-learning game built around four travel-themed activities:

- Country Race — match flags to English country names.
- Dialogues — choose a natural reply.
- Sentence Train — arrange words into a correct sentence.
- Where From? — match flags to “I’m from…” sentences.

There is no timer or lives system. Correct answers award 100 points plus a
streak bonus, and best scores are stored locally in the browser.

## Run locally

```bash
npm install
npm run dev
```

Open the displayed local URL. The root route redirects to `/english-game/`.
The standalone source is in `english-game/`; the deployable copy is in
`public/english-game/`.
